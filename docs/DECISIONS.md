# Decisions

Deviations and explicit trade-offs relative to `docs/plan/`.

| Date | Topic | Decision | Reason |
|---|---|---|---|
| 2026-10-02 | Host binding | Bind the demo API and UI to loopback by default | The plan deliberately excludes authentication; localhost is sufficient for the intended demo. |
| 2026-10-02 | Reopened PR duration | Exclude temporary closed intervals from waiting ledgers, but retain them in elapsed milestone durations | This follows the specified distinction between active waiting and calendar time. |
| 2026-10-02 | Linked delivery chains | Persist revert, reland and supersession links; defer chain-level elapsed delivery time | Explicit plan deferral; cycle time remains per PR. |
| 2026-10-02 | Windows verification | Run the exact uv subcommands from Makefile when GNU make is unavailable | Native PowerShell development uses the same ruff, mypy and pytest gates; Makefile remains the Linux/CI entrypoint. |
| 2026-10-02 | Dataset I/O boundary | Put load_dataset in db/dataset.py; keep immutable types in analytics/dataset.py | Preserves the explicit requirement that analytics computation has no I/O; API and worker share the same loader. |
| 2026-10-02 | Synthetic arrival interpretation | Apply area arrival multipliers to the weighted total Poisson arrival rate, then sample areas with adjusted weights | The plan specifies a daily rate and an area mix; this preserves the baseline total daily rate of 15 on weekdays and 5 on weekends. |
| 2026-10-02 | Concurrent snapshot computation | Allow deterministic duplicate computation and deduplicate in Postgres | Avoids a distributed lock on the read path; same identity has identical canonical content. |
| 2026-10-02 | API title | Use Delivery Insights API | The authoritative API contract overrides the shorter infrastructure example. |
| 2026-10-02 | Abstention wording | Treat 'not strong enough' as cautious abstention for V7b; retain the explicit V12 phrases when there are no candidates | Testing section 10 explicitly requires this V7b example although section 07 lists only 'insufficient' and 'not enough'. |
| 2026-10-02 | Unicode lint | Allow the Chinese punctuation and multiplication/range characters required by the bilingual contract | Preserve the exact prompt, templates and numeric unit grammar while keeping all other ruff rules. |
| 2026-10-02 | Human golden review | Keep B6 explicitly pending through subsequent local milestones | Automated independent arithmetic is complete; the agent cannot claim a human review. AGENTS permits stopping for human review only after delivery preparation. |
| 2026-10-02 | Shared container image build | Declare backend build only on api; migrate and worker reuse its tagged image | Clean-clone Compose acceptance exposed parallel BuildKit exports to the same tag failing with a missing parent snapshot. One build avoids the collision and redundant work. |
| 2026-10-02 | CLI logging | Share one JSON log configuration across uvicorn, arq bootstrap and application logging | Container acceptance exposed arq's default handler duplicating records as plain text; configuring before startup also makes bootstrap messages JSON. |
| 2026-10-02 | Post-approval CI sample | Compute the post-approval overlap median only for CI-covered approved-and-merged PRs (minimum 10), leaving it null without coverage. | Treating missing CI telemetry as zero would understate the observed delay; the overall coverage remains explicit. |
| 2026-10-02 | Sparse author-WIP correlation | Return null for fewer than 10 paired observations or a constant variable; tied ranks use their average. | The plan defines the correlation but no minimum; this uses the same minimum as driver groups and avoids misleading tiny-sample coefficients. |
| 2026-10-02 | Eval generator audit | Relands now use the ordinary review flow with a forced final merge, reverts use a different human developer, second approvals use the specified reviewer pool, and merged_by is the last approver. The single-reviewer area-B intervention omits second approvals because another local reviewer is unavailable. | Correct discrepancies found during the first offline eval (root-cause hit rate 0.75); no scoring thresholds or scenario multipliers were changed. This intentionally changes the seed-42 golden fixture. |
| 2026-10-02 | Size intervention in synthetic evaluation | Multiply current-period coding and author-revision durations by sqrt(size_mult), preserving the specified 3x size multiplier, all other scenario parameters, Bernoulli revert draws and production thresholds. | The specified size intervention changes approval probability but otherwise leaves work durations independent of size; both default seeds can show no cycle slowdown despite 3x larger PRs. This explicit fixture assumption makes the intended mechanism observable and is not an empirically fitted causal law. Rare quality baselines still abstain under the unchanged five-event gate. |
| 2026-10-02 | Confidence calibration scope | Report offline calibration only as performance on planted synthetic effects; defer real-history backtesting and human label calibration. | The scores express deterministic evidence strength, not estimated causal probabilities. No real Bedrock or repository validation is inferred from stub success. |
| 2026-10-02 | Frontend tooling | Use Vite 8.3.2, plugin-react 6 and Node 24; retain React 18 and Recharts 2. | The planned Vite 5 dependency tree reported two security advisories. The updated locked tree has zero npm audit findings. Node 20 is EOL; Node 24 is supported LTS. See https://vite.dev/guide/ and https://github.com/nodejs/Release. |
| 2026-10-02 | Dependency outage recovery | Restart the worker unless explicitly stopped, and format logged/uncaught exceptions as JSON with exception type only. | Final Redis outage testing exposed arq exiting after connection loss and exception tuples breaking the JSON formatter. Automatic restart restores collection; fixed messages avoid leaking upstream exception text. |
| 2026-10-02 | Live narrative repair | Version prompts as v3: retain the supplied system prompt and examples, append a concise authoring checklist, add length/low-hedge guidance in the user preamble, and report schema field/limit details during repair without echoing input. Eval reports include first-attempt violations. | Real Bedrock responses exceeded statement limits and mixed stronger hedges into optional low-confidence claims. Generic schema feedback did not identify the required correction. Validation thresholds and accepted output constraints are unchanged; prompt versioning invalidates prior cache identities. |
| 2026-10-02 | Local Bedrock eval credentials | `make eval` loads root `.env` through uv into the child process environment. | Matches Compose configuration and the user-provided key location while keeping credentials out of code, logs and Git; create `.env` from the empty example before running. |
| 2026-10-02 | Public-repository token scope | Omit requested-reviewer Team.slug from both GraphQL queries; retain the event, timestamp, Team type and individual reviewer login. Public CODEOWNERS team handles remain available. | Live GitHub rejected Team.slug with INSUFFICIENT_SCOPES for a repo-scoped classic token. Team request names do not affect analytics; omitting this optional metadata preserves the documented public-repository permission boundary. References: https://docs.github.com/en/graphql/guides/forming-calls-with-graphql and https://docs.github.com/en/graphql/reference/pulls#reviewrequestedevent. |
| 2026-10-02 | Frontend upstream refresh | Resolve the API service through Docker DNS every 10 seconds in a shared nginx upstream zone. | Recreating the API changed its address while nginx kept the startup address and returned 502. nginx 1.27.5 supports dynamic upstream resolution without reloading the UI container. Reference: https://nginx.org/en/docs/http/ngx_http_upstream_module.html#resolve. |

| 2026-10-03 | The user limited the live repository backfill to the completed 30-day stage. | Set local BACKFILL_DAYS=30 and PRECOMPUTE_DAYS=7,30; preserve already fetched records and report the configured target on a successful resume. Keep the distributable default at 180 days. | Avoid more historical collection while retaining valid checkpoints; 90/180-day live acceptance is explicitly out of this run's scope. |
| 2026-10-03 | Repeating Quickstart overwrote locally configured credentials. | Copy the example only when .env does not already exist, in both POSIX and PowerShell instructions. | The user identified running the unconditional copy command as the cause. Preserve existing settings on repeated setup; no credentials are recovered from logs or committed. |

| 2026-10-03 | User requested a simpler period-scoped dashboard, five initial attention rows and English narration. | Analytics 1.3.0 selects PRs created or with identified non-bot timeline activity in each report period, across all metrics, risks, CI, evidence and drilldowns. Previous comparisons use their own cohort; weekly series use their parent period cohort. The UI defaults to five risks and removes language selection, including legacy URL language state. | Supersedes the original all-open risk contract at the user's explicit request. Creation is sufficient; author actions count, but bot-only changes, unidentified commit actors and updatedAt alone do not. Existing flow exclusions, historical baselines, lifecycle durations, bilingual API support and the 30-day local backfill limit remain. Versioning prevents reuse of older snapshot/narrative caches. |
