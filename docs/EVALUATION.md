# Evaluation records

Current suites use analytics 1.5.0 and English-only prompt v8. Final offline and
real Bedrock suites passed all eight gates; the stage-8 trials and final per-case
results are appended below. The v6 suites are historical. Retired English trials v4 and v5 are
retained below, including their first-attempt validity failures. Historical
bilingual suites use older contracts and do not validate the current prompt.
Raw new reports are under ignored `backend/reports/`; older artifacts remain
recoverable in Git history. Violations include first-attempt and final errors.

Confidence is evidence strength, not a calibrated probability. Prompt refinement
used these same synthetic cases; this is not a held-out real-world causal benchmark.
