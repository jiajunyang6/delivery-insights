# Evaluation records

These tables retain the measured gates and per-case outcomes from the recorded
JSON reports. Offline results use analytics 1.4.0; the real Bedrock runs use 1.2.0.
The Bedrock suite has not been rerun for the later period-cohort changes.
Raw reports and screenshots remain recoverable in Git history; new evaluation
runs write JSON under ignored `backend/reports/`.

Confidence is evidence strength, not a calibrated probability. Prompt refinement
used these same synthetic cases; this is not a held-out real-world causal benchmark.

## Reproduce

From `backend/`:

```bash
uv run python -m insights_eval.run --llm stub
```

For credentialed Bedrock evaluation, use `make eval` from the repository root.
Each run writes its own report; credential-free CI runs the stub suite.
